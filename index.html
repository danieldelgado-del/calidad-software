Resumen

Este proyecto presenta el proceso de evaluación de calidad aplicado a un sistema de software mediante el uso de métricas de confiabilidad, eficiencia, mantenibilidad y usabilidad. A partir del análisis, se identifican fortalezas clave y oportunidades de mejora que permiten establecer un diagnóstico general del estado del producto. Los resultados evidencian un desempeño sólido, con áreas que pueden optimizarse mediante ajustes técnicos y de diseño.

Palabras clave: calidad de software, métricas, evaluación, análisis.

1. Introducción

La calidad del software es esencial para garantizar que un sistema funcione correctamente, sea confiable y cumpla con los requerimientos establecidos. En este documento se describe la evaluación realizada al software asignado, junto con las métricas aplicadas y los resultados obtenidos.

2. Marco Teórico

La norma ISO/IEC 25010 establece un modelo de calidad que agrupa características esenciales como mantenibilidad, usabilidad, confiabilidad y eficiencia. Las métricas permiten evaluar estos atributos de forma cuantitativa para determinar el nivel de calidad del sistema.

3. Metodología

Se utilizaron herramientas de inspección, análisis estático y pruebas funcionales. Las métricas evaluadas fueron:

  • Mantenibilidad
  • Confiabilidad
  • Usabilidad
  • Eficiencia

4. Resultados

Métrica Resultado Interpretación
Mantenibilidad 85% Código legible y fácil de modificar.
Confiabilidad 90% Pocos errores detectados.
Usabilidad 80% Interfaz comprensible.
Eficiencia 75% Rendimiento aceptable, puede mejorar.

Calificación Final: 82.5%

5. Discusión

El software presenta fortalezas en confiabilidad y mantenibilidad, demostrando una buena arquitectura. Sin embargo, se identifican oportunidades de optimización en eficiencia, especialmente en tiempos de carga y consumo de recursos.

6. Conclusiones

El sistema evaluado cumple con los estándares de calidad en la mayoría de métricas esenciales. Se recomienda continuar con mejoras orientadas a optimizar el rendimiento e interfaz del usuario.
